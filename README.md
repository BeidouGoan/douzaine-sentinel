# 斗在呢 · 工位哨兵

> 一台闲置安卓手机 + 一个本地视觉模型，把「人在不在工位」变成电脑能听懂的事件。
> 你一离开，电脑自动暂停播放、锁定屏幕；你回来，再恢复。
> **画面始终留在手机里，不联网、不上云、不用注册账号。**

---

## 它能做什么

把旧手机往桌上一放，镜头对着工位。它会一直看着，只判断一件事：**现在有没有人**。

- 起身接水、走开超过一段时间 → 自动暂停正在播放的音乐/视频，还可以锁屏
- 人回来 → 自动恢复播放
- 也可以只记录日志，看看自己一天真正在工位待了多久
- 动作完全可配：弹通知、锁屏、暂停/恢复播放、执行任意命令

**设计取向**：本地推理、局域网直连、零账号、双击即用。所有判断都在手机本地完成，传给电脑的只有「有人 / 无人」这类状态，没有图像、没有视频。

---

## 工作原理

```
   手机（看 + 判）                      电脑（做）
┌──────────────────┐              ┌──────────────────┐
│ 摄像头取帧        │              │  原生控制台       │
│   ↓              │   局域网 TCP  │   ↓              │
│ 本地目标检测      │  ──────────→  │  收到状态事件     │
│   ↓              │   逐行 JSON   │   ↓              │
│ 三态状态机        │              │  触发你的动作     │
│ 有人/待确认/无人   │              │  通知·锁屏·暂停   │
└──────────────────┘              └──────────────────┘
   画面不出手机                        不需要装任何东西
```

三步：**手机看 → 先等一等 → 电脑做**。

中间那个「待确认」很关键：不是镜头一看不到人就算走。画面连续几次没人，手机进入**待确认**，这段时间电脑不会做任何动作；确认真的走满了设定时长，才判定「无人」。低头捡东西、转身拿快递都不会误触发。

## 快速开始

### 1 · 手机装端

```bash
# 装 APK，并单独授一次相机权限
adb install -r DouZaiMa-v1.0.apk
adb shell pm grant com.yq.sentinel android.permission.CAMERA
```

或者直接用桌面图标打开，点「开始盯梢」。检测跑在前台服务里，锁屏也不会被系统杀掉。

### 2 · 电脑开控制台

双击 `斗在呢.exe`。它只会运行一个实例——重复双击会把已经开着的窗口唤出来，不会开出一堆。点窗口右上角 ✕ 是收进托盘（连接不断），彻底退出请在托盘图标上右键选「退出」。

### 3 · 连上手机

在「手机地址」那一栏：

- **插 USB 共享网络**：留空，自动探测，最稳。
- **同一 WiFi**：把手机主界面底部那行地址点一下复制，粘进来。

连上后左上角会变成绿色的「有人」。连不上时日志会直接写原因，掉线会按 5 → 10 → 20 → 30 秒自动重连。

### 4 · 配好动作，保存

「人离开」和「人回来」各自一套动作与缓冲，互不干扰。改完点「保存配置」，写进同目录的 json。

> ⚠️ 实际触发延迟是**叠加**的：手机端确认时长 + 电脑端额外缓冲。手机端那段是用来防误判的，一般别调小于 5 秒。

## 参数怎么调

大部分情况默认值就够。真正可能动的是这两个：

| 参数 | 默认 | 调它会发生什么 |
|---|---|---|
| 离开确认时长 | 8 秒 | 调大更不容易误判，但真走了也要更久才反应 |
| 多像才算人 | 0.4 | 调高更严格（人不动也可能判成无人），调低更容易认出人但可能把椅背当人 |

电脑端另有「额外缓冲」「冷却」等，改完即时生效，点「保存配置」才写盘。

## 常见问题

**电脑连不上手机？**
按顺序排查：① 手机端有没有点「开始盯梢」；② 两台设备是否同一网段；③ 路由器有没有开「AP 隔离 / 客户端隔离」；④ 地址栏是不是残留了旧 IP——留空让它重新探测。

**人明明坐着却判成「无人」？**
先看手机端那个「有多确定」的数值。长期偏低说明人太小或逆光，把手机挪近、镜头抬到胸口高度，或把「多像才算人」调低一档。数值正常但状态跳，就把「离开确认时长」加到 10~12 秒。

**会不会很耗电？**
它只在本地做判断，不像录像那样一直写文件，比想象中省。长期跑建议接上充电器，并在系统设置里允许后台运行。

**画面会上传吗？**
不会。判断完全在手机本地完成，没有图像、视频上传，没有云端账号。

**能用在别的手机上吗？**
安卓 7.0 以上基本都能装，不挑品牌和芯片。不同品牌主要差别在后台保活策略。

## 自己编译

需要 JDK 21 + Android SDK + Gradle 8.7；电脑端只需 Windows 自带的 .NET Framework 4.8 编译器。

```bash
# 手机端出包 → 项目根目录 DouZaiMa-v1.0.apk
bash package.sh                # Windows 上也可双击 package.cmd

# 电脑端编译（不需要 Visual Studio）
pc\console\build.cmd           # 同时自动生成所有别名 exe
```

`build.cmd` 每次都会自动同步三个入口 exe，无需手动复制。命令行自检：`DouZaiNeDebug.exe --selftest`。

## 目录结构

```
src/main/java/com/yq/sentinel/
  ├ detect/          本地目标检测（MediaPipe Tasks）
  ├ affinity/        CPU 小核绑定封装
  ├ presence/        有人/待确认/无人 三态状态机
  ├ net/             事件上报 TCP Server / 本机地址获取
  ├ camera/          Camera2 取帧 + YUV 转换
  └ SentinelService.kt  前台服务
src/main/cpp/       绑核 JNI
pc/console/         电脑端控制台源码（C# WinForms）
bench/              性能对照测量脚本
probe/              设备能力探测脚本
docs/               设计与实测文档
```

## 隐私与安全

- **画面不出手机**：所有视觉推理都在设备本地完成，上传的只有状态文本。
- **局域网直连**：手机和电脑在同一网络内通信，不经过任何第三方服务器。
- **零账号**：没有注册、登录、云端同步。
- **无设备标识**：仓库与发布物不包含任何设备序列号或个人身份信息。
