日志

「有人/无人」状态每秒刷新一次，但只在状态变化时记日志，避免刷屏。

动作

exec 用 shell 执行，会真的运行。留空则不执行。

触发

延迟是叠加的：实际触发延迟 ≈ 手机端「离开确认时长」（默认 8 秒） + 这里的「额外缓冲」。
手机端那 8 秒用于防「低头/侧身被误判成离开」，所以这里的额外缓冲默认 0。

连接

需先用 adb 连接手机。手机端启动：
adb shell am start -n com.yq.sentinel/.MainActivity --ez autostart true --ez pin true
